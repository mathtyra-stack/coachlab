📄 Termos de Uso
envolvi — Personal Trainer OS
Vigência: a partir de 05/05/2026

1. Aceitação dos Termos

Ao utilizar o envolvi e ao cadastrar seus dados pessoais, você concorda integralmente com estes Termos de Uso e com nossa Política de Privacidade.

2. Descrição do Serviço

O envolvi é uma plataforma de gestão voltada para personal trainers, que permite o gerenciamento de alunos, treinos, cobranças e agenda. Os dados são armazenados localmente no seu dispositivo (IndexedDB e localStorage).

3. Dados Coletados

Para a prestação dos serviços, coletamos os seguintes dados dos alunos:

  • Dados de identificação: nome completo, contato (WhatsApp)
  • Dados demográficos: data de nascimento, sexo, altura
  • Dados físicos: peso, medidas corporais, composição (quando fornecidos)
  • Dados financeiros: plano contratado, valores de mensalidade, registros de pagamentos
  • Dados de treinamento: protocolos de treino, objetivos, desempenho
  • Imagens: quando expressamente autorizadas pelo titular

4. Finalidade do Tratamento

Os dados são utilizados exclusivamente para:

  • Gerenciamento do relacionamento coach–aluno
  • Elaboração e acompanhamento de planos de treino
  • Controle financeiro e emissão de cobranças
  • Comunicação via WhatsApp para envio de treinos

5. Armazenamento e Segurança

Todos os dados são armazenados localmente no dispositivo do coach, sem envio a servidores externos. O coach é responsável pela segurança do acesso ao dispositivo. Recomendamos uso de senha no dispositivo, acesso via HTTPS e realização de backups regulares através da função "Exportar backup".

6. Compartilhamento de Dados

Os dados dos alunos não são compartilhados com terceiros, exceto quando o coach envia o treino via WhatsApp mediante solicitação ou consentimento do próprio aluno.

7. Seus Direitos

Nos termos da Lei 13.709/2018 (LGPD), o titular dos dados tem direito a:

  • Confirmar a existência de tratamento
  • Acessar seus dados
  • Corrigir dados incompletos ou desatualizados
  • Solicitar a anonimização, bloqueio ou eliminação
  • Revogar o consentimento a qualquer momento

8. Exclusão de Dados

O aluno pode solicitar a exclusão completa de seus dados ao coach responsável. A exclusão é realizada diretamente no sistema e remove permanentemente todos os registros associados ao titular.

9. Retenção de Dados

Os dados são mantidos enquanto o vínculo coach–aluno estiver ativo. Após encerramento, os dados serão excluídos mediante solicitação ou por iniciativa do coach.

10. Contato

Em caso de dúvidas ou solicitações relacionadas à privacidade, entre em contato diretamente com o seu personal trainer responsável.

🛡 Política de Privacidade
envolvi — Personal Trainer OS
Vigência: a partir de 05/05/2026

1. Controlador dos Dados

O controlador dos dados pessoais tratados nesta plataforma é o personal trainer responsável pelo cadastro, que utiliza o envolvi como ferramenta de gestão de alunos.

2. Quais dados coletamos

Dados pessoais básicos

  • Nome completo
  • Número de WhatsApp
  • Data de nascimento
  • Sexo (opcional)

Dados físicos e de saúde (sensíveis)

Coletados apenas mediante consentimento específico e informado:

  • Altura, peso, medidas corporais
  • Imagens (fotos de acompanhamento)
  • Histórico de treinos e desempenho físico
  • Restrições físicas e observações de saúde

Dados financeiros

  • Plano contratado, valores e histórico de pagamentos

3. Base Legal

O tratamento se fundamenta nas seguintes bases legais (art. 7º e 11 da LGPD):

  • Consentimento: dados sensíveis (físicos e imagens) mediante autorização expressa
  • Execução de contrato: dados necessários para prestação do serviço
  • Legítimo interesse: comunicação sobre treinos e cobranças

4. Como os dados são armazenados

Todos os dados ficam armazenados localmente no dispositivo do coach (banco de dados IndexedDB do navegador). Nenhum dado é enviado a servidores externos. O coach é o único com acesso.

Recomendações de segurança: use sempre HTTPS, mantenha o dispositivo protegido com senha e faça backups regulares.

5. Retenção e Exclusão

Os dados são mantidos enquanto o vínculo entre coach e aluno estiver ativo. O aluno pode solicitar a exclusão completa de seus dados ao coach. A exclusão remove permanentemente todos os registros do sistema.

Política de retenção: dados mantidos enquanto a conta/vínculo estiver ativo. Excluídos mediante solicitação formal ao responsável.

6. Direitos do Titular

Conforme a LGPD (art. 18), você tem direito a:

  • Acesso: solicitar cópia dos seus dados
  • Correção: atualizar dados incorretos
  • Exclusão: solicitar remoção completa
  • Portabilidade: receber seus dados em formato estruturado
  • Revogação do consentimento: retirar autorização a qualquer tempo
  • Informação: saber com quem seus dados são compartilhados

7. Compartilhamento

Os dados não são compartilhados com terceiros para fins comerciais. O envio de treinos via WhatsApp é feito pelo coach diretamente ao titular, sem intermediários.

8. Exercício dos Direitos

Para exercer seus direitos, entre em contato com o personal trainer responsável pelo seu cadastro. A solicitação será atendida em até 15 dias úteis.
